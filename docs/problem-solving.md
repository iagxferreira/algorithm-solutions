# Problem Solving

The goal is not memorization. The goal is recognizing structure.

## The Usual Progression

Theory -> data structure -> invariant -> implementation -> tests -> complexity -> pattern -> problems -> reflection

## Questions To Ask

Before solving a problem, ask:

- What is the input shape?
- What are the constraints?
- What is the brute force approach?
- Where is the bottleneck?
- Which invariant will keep the solution correct?
- Which data structure makes the invariant easy to maintain?

## Three-Solution Rule

When useful, work through:

- brute force
- improved
- optimal

This shows why the optimization exists, not just what the final answer is.

## Reflection

After solving, record:

- what pattern was used
- what you missed initially
- what edge case was tricky
- what the JVM did that mattered
