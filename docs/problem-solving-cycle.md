# Problem Solving Cycle

This repository is set up so each problem becomes a learning artifact, not just a submission.

## Workflow

Understand -> Constraints -> Brute Force -> Bottleneck -> Pattern Recognition -> Data Structure -> Invariant -> Algorithm -> Correctness -> Kotlin Implementation -> Tests -> Complexity -> Reflection -> Revisit

## First Study Set

1. Two Sum
2. Contains Duplicate
3. Valid Anagram
4. Group Anagrams
5. Product of Array Except Self
6. Valid Palindrome
7. Two Sum II
8. Best Time to Buy and Sell Stock
9. Longest Substring Without Repeating Characters
10. Longest Repeating Character Replacement

## Ground Rules

- Do not jump straight to the optimal answer.
- Write the brute-force baseline first.
- Identify the bottleneck before optimizing.
- Prove correctness before considering the code complete.
- Record what the JVM or Kotlin details changed about the implementation.
